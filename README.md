# 星光雕刻工坊 · 写实直播工作室

按用户参考图制作的写实互动场景，以 **1080 × 1920、9:16** 为直播画布。雕刻时自动推近头像，完成后切到近俯视相机，清晰展示成品与作品效果分，再退回全景出料；默认约 **10 秒 / 件**。普通预览右上角齿轮打开控制台；加工速度、评论、点赞、礼物、批量排队、暂停、重置、最近作品与排行榜均在控制台内。

## 启动

在本目录启动任意静态 HTTP 服务器，例如：

```powershell
python -m http.server 8080
```

然后打开 http://127.0.0.1:8080/ 。不要直接双击 HTML；项目使用 ES 模块。

- 普通预览：`http://127.0.0.1:8080/`，点击右上角齿轮；Esc 关闭控制台。
- 纯直播画面：`http://127.0.0.1:8080/?live=1`，隐藏所有控制按钮、侧栏和遮罩，只输出工作室场景。
- 同一浏览器内的两个标签可通过 BroadcastChannel 同步模拟事件、重置和换盘请求。OBS 独立浏览器与 Chrome 的跨进程同步不保证有效。
- 启动后自动演示 5 件作品；继续演示可开启「自动模拟新观众」（默认约每 10.5 秒一位，随加工速度调整，最多保留 2 位等待）。
- 控制台「加工速度」提供 1×、1.5×、1.8×、2×、2.5×，对应约 18、12、10、9、7.2 秒 / 件；默认 1.8×。切速不重置当前作品，选择会保存到本浏览器，并同步到同浏览器已打开的直播标签。

## OBS 设置

在 OBS「设置 → 视频」中，将基础画布与输出分辨率均设为 **1080 × 1920**。添加「浏览器」源，URL 填入 `http://127.0.0.1:8080/?live=1`，宽度填 **1080**、高度填 **1920**，帧率设为 **60 FPS**。浏览器源与画布保持同尺寸并适配画布，不需要额外裁切。

直播地址在该尺寸下铺满画布，无页面边框、控制图标或留白。普通浏览器预览始终保持 9:16，在横向窗口中居中缩放。加工时镜头平滑推近夹具，完成展示后退回全景；上料、搬运和收料保留完整物料路径。

## 写实画面的实现

采用高保真图片底图与 Canvas 2D 分层动态合成，画布固定为 1080 × 1920。整机布局沿用 `output/structure-concept-v3.png`：左侧供料轨道、真空吸取机械臂、上方雕刻头、左右运行的输送带，以及右侧滑道和接料盘。当前整机底图为 `assets/workcell-exchange-base-v1.png`，在历史真空定位座底图 `assets/approved-cell-vacuum-v3.png` 上移除了固定收料盘；盘体由独立透明素材合成，以便完整退出画面和返回。低矮金属定位座仍通过浅槽定位、底部吸附固定圆片，保留真实气管、接头和安装螺钉，头像表面完全露出。

统一机械时钟为 **18 秒**，默认以 **1.8×** 播放，完整周期约 **10 秒**：机械臂吸取毛坯 → 放入定位座 → 底部真空吸附、逐行雕刻 → 雕刻头关光归位 → 成品近俯视展示与评分 → 定位座解除吸附、机械臂取走成品 → 放到输送带左侧空位 → 机械臂退开、输送带同步步进 → 最右成品沿滑道进入接料盘。默认雕刻约 **2 秒**，成品展示约 **2.5 秒**；速度会同时作用于各个机械阶段。头像只在激光已经经过的区域显现。这是动画演示节奏，不是实机加工参数。

扫描采用 **16 趟平滑机械往复 × 每趟 4 条局部细纹，共 64 条显影细纹**，减弱粗条带揭图的感觉。四条细纹沿同一机械横向位置推进，光点在垂直方向的局部偏移不超过照片平面 0.8 像素；显影遮罩逐条跟随实际扫过的区域，换行时关光。扫描仍占 3.6 秒机械时钟，默认约 2 秒，不改变整轮加工节奏。

定位座的接触面已按圆片底面高度重新校准，激光轨迹和吸盘取放落点共用印面中心 `(530,891)`。旧底图的大圆环、静态爪块和额外绘制的绿色夹爪已移除；真空固定不会用爪块覆盖头像。

加工近景放大 **7.85 倍**，圆片头像在 1080 宽输出中的直径约 **649 像素，占画面宽度 60%**。镜头统一作用于机架、工具、圆片、阴影与激光；物料尺寸和透视关系保持一致。加工完成、雕刻头关光归位后，切换到同一真空定位座的独立近俯视相机：头像直径 **756 像素，占画面宽度 70%**，印面接近正圆，默认展示 **2.5 秒**。该视角仍显示定位座上同一件成品，不增加额外物料。搬运、皮带和滑槽阶段镜头已经退回全景，圆片不会因推近而被裁掉。

为避免整机照片推近后变糊，加工镜头推进到最后 20% 时，会平滑淡入 `assets/machining-detail-plate-v1.png` 高清空夹具底板。该底板由内置 imagegen 去掉活动件并重建细节；真正的动态雕刻头、逐行扫描和当前头像仍由同一套程序实时绘制，画面不是预录视频。底板按统一比例映射回照片坐标，头像占宽仍约 60%，不改变材料尺寸。

成品展示期间，画面下方显示 **0–100 的「作品效果分」**，从 0 动画计到结果，并显示一句短评和清晰度、构图、色彩三个指标。算法只分析头像圆形内区的图像表现，同一张头像得到稳定结果；透明、空白和平色图像分数较低，随机噪点不会因边缘较多而获得高分。此分数评价作品图像效果，**不是颜值分**，不评价人物外貌或人格。

成品放到传送带后，各自上方显示暖金色分数标签，并随圆片一起步进；初始演示片也使用同一套图像评分。分数保存在成品记录中，跨周期不会串到其他作品。进入滑槽时标签淡出，加工和成品特写时隐藏皮带标签。

输送带与圆片使用同一个透视平面，四个工位在输送方向上等距分布，圆片的金边、头像和接触阴影一起移动。圆片材料由 `coin-material.js` 实时绘制，包含金属倒角、细微车纹、侧壁和随空间位置变化的环境反射；反射不依赖时间随机闪烁，也不额外生成头像贴图。已经停稳的成品使用材质缓存，雕刻与移动中的圆片实时绘制，减少满盘时的重复绘制和临时缓存占用。

每件成品具有唯一编号；跨周期保留输送带与接料盘里的作品，送出带端后继续沿可见滑道落入盘中。接料盘容量为 **24 件**，满盘后自动执行 **3.8 实际秒**的换盘动作，期间保留等待队列并停止开启下一件加工：盘体、盘内成品和阴影一起沿导轨向右退出，在完全离开画面后交接库存，再将空盘沿原路送回。空盘归位后才继续加工，成品不会在可见盘内直接消失。换盘时长不随加工速度变化，暂停会冻结动作。

在普通预览中打开控制台，点击 **「更换收料盘」** 可以提前换盘；如果当前正在加工，先等本轮成品完成落料再退出收料盘。重复请求不会重启动作，重置会取消换盘并恢复初始状态；同浏览器直播标签可同步换盘请求。纯直播模式仍只显示 1080 × 1920 场景。

机架固定，镜头与机械运动由分层图像合成实现。取放臂在水平世界平面内求解刚性连杆，再投影回照片；升降由腕部独立伸缩。当前演示头像改用 `assets/portrait-artwork-atlas-v1.png`：内置 imagegen 以用户参考图上的四张成品为参照重绘的高清平面插画，替代过去约 130px 宽的低清裁图。图集为 1254 × 1254、2 × 2 排列，每张原始插画 627 × 627；`makeAvatar` 默认输出 768 × 768 圆形画布。加工、独立成品相机和输送带使用同一头像来源，同名观众稳定映射到同一张演示头像。

## 文件

- `index.html`：纯场景与隐藏式控制台。
- `styles.css`：9:16 响应式预览、控制台和无控件的直播样式。
- `photo-scene.js`：1080 × 1920 画布、分层机械运动、头像与激光的 Canvas 合成引擎。
- `handling-cycle.js`：18 秒上下料、夹紧、雕刻、成品展示与传送的统一机械时钟。
- `live-camera.js`：加工近景、成品展示和完整出料全景的连续镜头。
- `showcase-view.js`：独立近俯视成品相机、70% 画面宽头像与定位座接触高度校准。
- `portrait-score.js`：按 RGBA 像素计算稳定的清晰度、构图、色彩与作品效果分。
- `score-overlay.js`：成品相机下方的计分动画、短评和三个指标。
- `coin-material.js`：圆片金属倒角、车纹、位置反射和跟随扫描细纹的头像遮罩。
- `tray-exchange.js`：3.8 实际秒的满盘退出、屏外交接、空盘返回与归位状态。
- `production-speed.js`：五档速度、周期时长和不跳过动作的生产时间积分。
- `pick-arm.js`：可见机械臂、连杆、吸盘与真空管的绘制。
- `belt-plane.js`：输送面透视投影、四个工位和滑道出口坐标。
- `cell-inventory.js`：物料唯一编号、跨周期归属与 24 件接料盘库存。
- `main.js`：事件、队列、打印时间轴、榜单与跨标签同步。
- `art.js`：高清头像图集取样、默认 768 × 768 圆形画布与缓存。
- `assets/workshop-reference.png`：用户提供原图。
- `assets/workshop-blank.png`：内置 imagegen 编辑生成的空白徽章场景。
