# 星光雕刻工坊 · 写实直播工作室

按用户参考图制作的写实互动场景，以 **1080 × 1920、9:16** 为直播画布。打印时雕刻头随扫描轨迹移动，激光与头像显影保持同步。普通预览右上角齿轮打开控制台；评论、点赞、礼物、批量排队、暂停、重置、最近作品与排行榜均在控制台内。

## 启动

在本目录启动任意静态 HTTP 服务器，例如：

```powershell
python -m http.server 8080
```

然后打开 http://127.0.0.1:8080/ 。不要直接双击 HTML；项目使用 ES 模块。

- 普通预览：`http://127.0.0.1:8080/`，点击右上角齿轮；Esc 关闭控制台。
- 纯直播画面：`http://127.0.0.1:8080/?live=1`，隐藏所有控制按钮、侧栏和遮罩，只输出工作室场景。
- 同一浏览器内的两个标签可通过 BroadcastChannel 同步模拟事件和重置。OBS 独立浏览器与 Chrome 的跨进程同步不保证有效。
- 启动后自动演示 5 件作品；继续演示可开启「自动模拟新观众」（约每 16.7 秒一位）。

## OBS 设置

在 OBS「设置 → 视频」中，将基础画布与输出分辨率均设为 **1080 × 1920**。添加「浏览器」源，URL 填入 `http://127.0.0.1:8080/?live=1`，宽度填 **1080**、高度填 **1920**，帧率设为 **60 FPS**。浏览器源与画布保持同尺寸并适配画布，不需要额外裁切。

直播地址在该尺寸下铺满画布，无页面边框、控制图标或留白。普通浏览器预览始终保持 9:16，在横向窗口中居中缩放；参考图通过等比例轻微裁切适配画布，不拉伸机器比例。

## 写实画面的实现

采用高保真图片底图与 Canvas 2D 分层动态合成，画布固定为 1080 × 1920。当前结构以已确认的 `output/structure-concept-v3.png` 为准：左侧供料轨道、真空吸取机械臂、中央夹具、上方雕刻头、前方左右运行的输送带，以及右侧滑道和独立接料盘。机架、玻璃、金属反射与环境保留参考图的质感。

完整加工周期为 **16.2 秒**：机械臂下探吸住毛坯 → 抬升并移动至夹具 → 下放并释放 → 机械臂退回、夹具锁紧 → 雕刻头定位并完成 14 行往复扫描 → 关光退刀、松夹 → 机械臂吸取成品 → 抬升并放到输送带左侧空位 → 机械臂退开、输送带同步步进 → 最右成品经过滚筒和滑道进入接料盘 → 稳定后开始下一轮。头像只在激光已经经过的区域显现。16.2 秒是演示节奏，不是实机加工参数。

输送带与圆片使用同一个透视平面，四个工位在输送方向上等距分布，圆片的金边、头像和接触阴影一起移动。每件成品具有唯一编号；跨周期保留输送带与接料盘里的作品，送出带端后继续沿可见滑道落入盘中。接料盘容量为 **24 件**，满盘后停止开启下一件加工，等待队列保留。在普通预览中打开右上角控制台，点击 **「人工取走收料盘成品」** 模拟取走盘内成品后，可继续加工；这项操作仅移走盘内作品，不重置输送带或正在加工的作品。纯直播模式仍只显示 1080 × 1920 场景。

相机与机架固定，机械运动由分层图像合成实现。取放臂在水平世界平面内求解刚性连杆，再投影回照片；升降由腕部独立伸缩。为保持照片质感，当前演示头像从用户提供参考图的四张成品头像中取样，同名观众稳定映射到同一头像。

## 文件

- `index.html`：纯场景与隐藏式控制台。
- `styles.css`：9:16 响应式预览、控制台和无控件的直播样式。
- `photo-scene.js`：1080 × 1920 画布、分层机械运动、头像与激光的 Canvas 合成引擎。
- `handling-cycle.js`：16.2 秒上下料、夹紧、雕刻与传送的统一阶段时钟。
- `pick-arm.js`：可见机械臂、连杆、吸盘与真空管的绘制。
- `belt-plane.js`：输送面透视投影、四个工位和滑道出口坐标。
- `cell-inventory.js`：物料唯一编号、跨周期归属与 24 件接料盘库存。
- `main.js`：事件、队列、打印时间轴、榜单与跨标签同步。
- `art.js`：参考图头像取样与缓存。
- `assets/workshop-reference.png`：用户提供原图。
- `assets/workshop-blank.png`：内置 imagegen 编辑生成的空白徽章场景。
- `assets/workshop-motion-plate.png`：移除静态雕刻头的历史底板。
- `assets/workshop-empty-stage.png`：空工作夹具、空进料轨道与空传送带底板，供完整进出料合成使用。
- `output/structure-concept-v3.png`：已确认的自动上下料工作站结构效果图与几何参照。
- `assets/approved-cell-clean.png`：新版动态合成使用的空工作站底板。
- `assets/spindle-layer.png`：可移动的雕刻头图层。
- `ASSET-NOTES.md`：生成方式与完整提示词。
- `scene.js`、`vendor/`：保留的上一版 Three.js 实现，当前页面不加载。

当前方案预览为 `PREVIEW-approved-1080x1920.png` 和 `PREVIEW-approved-1080x1920.webm`；其他 PREVIEW 文件保留作历史对照。
