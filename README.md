# 星光雕刻工坊 · 写实直播工作室

按用户参考图制作的写实互动场景，以 **1080 × 1920、9:16** 为直播画布。整机镜头保持固定，上方青色悬浮实况窗按规则启用，同步放大显示当前圆片、雕刻头、激光和显影进度，并用引线跟随实际雕刻头的右侧锚点，完成后揭晓作品效果分；默认约 **10 秒 / 件**。直播接入使用独立网页后台；离线模拟保留普通预览右上角齿轮控制台。

## 接入直播与后台（推荐）

在本目录的 PowerShell 中启动：

```powershell
.\start-studio.ps1
```

脚本依次使用本项目 `.venv`、`D:/PythonProjects/douyin-browser-ws-relay/.venv` 或 PATH 中的 Python，启动本地工作室服务；不安装依赖，也不自动启动抖音采集器。后台和直播页使用同一服务：

- 配置后台：[http://127.0.0.1:8082/admin/](http://127.0.0.1:8082/admin/)。
- 纯直播画面：[http://127.0.0.1:8082/?live=1](http://127.0.0.1:8082/?live=1)。
- 普通预览：[http://127.0.0.1:8082/](http://127.0.0.1:8082/)。

需要修改端口或外部采集项目位置时：

```powershell
.\start-studio.ps1 -Port 8083 -RelayProjectPath 'D:/PythonProjects/douyin-browser-ws-relay'
```

首次启动只从外部 relay 项目配置中读取 `ROOM_ID`、`RELAY_WS_BASE` 和 `VIEW_TOKEN` 作为初始连接设置。Cookie、签名 WSS 和 `INGEST_TOKEN` 不导入工作室；外部项目文件不作修改。工作室将自身配置保存在已被 Git 忽略的 `.local` 目录中，VIEW_TOKEN 由服务端保管，不写进直播页或前端存储。后台可以修改连接配置，无需编辑代码。

后台提供入场打印开关、同一用户重复入场冷却时间、等待队列上限、礼物优先处理、礼物触发条件、特写模式（仅礼物 / 全部 / 关闭）和加工速度，并可暂停、继续、清空等待队列和更换收料盘。在仅礼物模式下，符合条件的礼物为对应观众的作品启用特写；特写仍采用固定整机上方的青色实况窗，不切换整机镜头。礼物累计连击按用户、礼物和连击组取增量，相同数量的结束包不会反复触发。

实时事件由服务端统一排队，跨 Chrome、OBS 等浏览器连接同一服务；只有第一个连接的显示页负责执行加工，后台不参与打印。观看或配置后台不会额外加工一份。后台显示连接状态、近期事件与队列；头像经同源代理载入，失败时回退到演示头像，并在状态中标明，避免将示例误认为真实头像。演示模式与真实接入分开配置。

### 启动原抖音转发链路

本项目消费用户提供项目的统一 WebSocket 事件，不代替上游采集器。真实接入前，应按 `D:/PythonProjects/douyin-browser-ws-relay/README.md` 启动原 `cloud_server.py`、DyHub 的 `lightweight` 内核和 `dyhub_bridge.py`。云端转发消费地址为 `{RELAY_WS_BASE}/events/{ROOM_ID}?token={VIEW_TOKEN}`，由本项目服务端建立连接；不要把 VIEW_TOKEN 手工放进 OBS 的页面 URL。若使用已有云端网关，则连接其地址，云端和本机房间号及凭据需要匹配。

入场消息 `member` 触发头像排队，礼物 `gift` 按后台规则优先处理并启用特写；普通弹幕、点赞不会被当成入场。抖音只向采集连接推送部分进场消息，无法保证每位进房观众都能被检测。原 relay 是内存广播，断线期间的事件不会补发。本项目的模拟测试不代表已经验证某个真实直播间可采集；后台显示「已连接」也只表示转发连接建立，应结合最近实际入场和礼物事件确认。

## 离线画面预览（静态服务）

不接入直播时，仍可在本目录启动任意静态 HTTP 服务器，例如：

```powershell
python -m http.server 8080
```

然后打开 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)。这是原有本地模拟模式，没有后台服务或真实抖音转发连接。不要直接双击 HTML；项目使用 ES 模块。

- 普通预览：`http://127.0.0.1:8080/`，点击右上角齿轮；Esc 关闭控制台。
- 纯直播画面：`http://127.0.0.1:8080/?live=1`，隐藏所有控制按钮、侧栏和遮罩，只输出工作室场景。
- 同一浏览器内的两个标签可通过 BroadcastChannel 同步模拟事件、重置和换盘请求。OBS 独立浏览器与 Chrome 的跨进程同步不保证有效。
- 启动后自动演示 5 件作品；继续演示可开启「自动模拟新观众」（默认约每 10.5 秒一位，随加工速度调整，最多保留 2 位等待）。
- 控制台「加工速度」提供 1×、1.5×、1.8×、2×、2.5×，对应约 18、12、10、9、7.2 秒 / 件；默认 1.8×。切速不重置当前作品，选择会保存到本浏览器，并同步到同浏览器已打开的直播标签。

## OBS 设置

在 OBS「设置 → 视频」中，将基础画布与输出分辨率均设为 **1080 × 1920**。添加「浏览器」源，真实接入时 URL 填入 `http://127.0.0.1:8082/?live=1`（端口与启动脚本一致）；静态模拟使用 `http://127.0.0.1:8080/?live=1`。宽度填 **1080**、高度填 **1920**，帧率设为 **60 FPS**。浏览器源与画布保持同尺寸并适配画布，不需要额外裁切。

直播地址在该尺寸下铺满画布，无页面边框、控制图标或留白。普通浏览器预览始终保持 9:16，在横向窗口中居中缩放。主镜头在上料、加工、评分、搬运和换盘期间保持固定，上方悬浮实况窗与下方整机同时可见；输送带、滑槽和收料盘保留完整物料路径。

## 写实画面的实现

采用高保真图片底图与 Canvas 2D 分层动态合成，画布固定为 1080 × 1920。画面上方使用既有工作站照片的上部裁切与浅景深作为环境，青色实况窗、角标、暖金标签、淡网格和引线由 Canvas 原生绘制。整机布局沿用 `output/structure-concept-v3.png`：左侧供料轨道、真空吸取机械臂、上方雕刻头、左右运行的输送带，以及右侧滑道和接料盘。整机底图为 `assets/workcell-exchange-base-v1.png`，盘体由独立透明素材合成，以便完整退出画面和返回。低矮金属定位座通过浅槽定位、底部吸附固定圆片，保留真实气管、接头和安装螺钉，头像表面完全露出。

统一机械时钟为 **18 秒**，默认以 **1.8×** 播放，完整周期约 **10 秒**：机械臂吸取毛坯 → 放入定位座 → 底部真空吸附、逐行雕刻 → 雕刻头关光归位 → 实况窗中展示成品与评分 → 定位座解除吸附、机械臂取走成品 → 放到输送带左侧空位 → 机械臂退开、输送带同步步进 → 最右成品沿滑道进入接料盘。默认雕刻约 **2 秒**，成品评分展示约 **2.5 秒**；速度会同时作用于各个机械阶段。头像只在激光已经经过的区域显现。这是动画演示节奏，不是实机加工参数。

扫描采用 **16 趟平滑机械往复 × 每趟 4 条局部细纹，共 64 条显影细纹**，减弱粗条带揭图的感觉。四条细纹沿同一机械横向位置推进，光点在垂直方向的局部偏移不超过照片平面 0.8 像素；显影遮罩逐条跟随实际扫过的区域，换行时关光。扫描仍占 3.6 秒机械时钟，默认约 2 秒，不改变整轮加工节奏。

定位座的接触面已按圆片底面高度重新校准，激光轨迹和吸盘取放落点共用印面中心 `(530,891)`。旧底图的大圆环、静态爪块和额外绘制的绿色夹爪已移除；真空固定不会用爪块覆盖头像。

悬浮实况窗位于输出画面的 `(135,205)`，尺寸 **810 × 395**，宽度占直播画面的 **75%**；内部使用固定 **1024 × 512** 画布。窗内背景复用现有工作站照片上部的虚化环境，不显示定位座、夹爪或吸盘，也不加载历史空夹具底图。圆片向左放大，水平轴倾斜约 **−13.7°**，露出金属侧壁；上方只呈现雕刻头的末端聚焦镜筒。右侧显示实际扫描进度、扫描条数和当前阶段，底部暖金胶囊显示昵称、进度或完工评分；这些数据来自生产时钟，不虚构激光功率或加工精度。窗内圆片、镜筒和激光按固定投影实时重绘：头像来源、物料编号、机械位置、逐条显影遮罩与下方加工位共用同一记录和同一扫描时钟。实况窗图像不计入物理库存。

上料和取料时，窗内圆片沿实际机械搬运路径移动，并裁切在实况视口内；圆片离开后只保留虚化环境。下方整机仍完整显示吸盘取放与定位座，物料不会凭空进入加工位。成品转入输送带、待机或换盘时，实况窗不保留上一件头像。只有当前物料位于夹具时才显示引线，引线从浮窗底边连接到活动雕刻头右侧小锚点，随扫描、升降和归位一起移动。暂停会冻结加工与显影进度，并同步显示暂停状态。

加工特效由 `laser-effects.js` 实时绘制：激光接触点具有白热核心与青色辉光，短暂金属火花从接触点飞出，少量半透明烟雾上升。光束、辉光、火花和烟雾仅在实际扫描激光开启且未暂停时显示，换行、搬运、成品评分和暂停期间关闭。特效时间可重复采样，不会改变机械路径或显影区域。本轮未新增 AI 位图。

成品展示期间，实况窗显示 **0–100 的「作品效果分」**，从 0 动画计到结果，并显示观众昵称和一句短评；加工时显示雕刻进度与阶段。评分在加工完成、雕刻头归位后揭晓。算法按清晰度、构图和色彩分析头像圆形内区，同一张头像得到稳定结果；透明、空白和平色图像分数较低，随机噪点不会因边缘较多而获得高分。此分数评价作品图像效果，**不是颜值分**，不评价人物外貌或人格。

成品放到传送带后，各自上方显示暖金色分数标签，并随圆片一起步进；初始演示片也使用同一套图像评分。分数保存在成品记录中，跨周期不会串到其他作品。加工和浮窗评分展示期间，皮带上的标签始终可见；对应成品进入滑槽时标签淡出。

输送带与圆片使用同一个透视平面，四个工位在输送方向上等距分布，圆片的金边、头像和接触阴影一起移动。圆片材料由 `coin-material.js` 实时绘制，包含金属倒角、细微车纹、侧壁和随空间位置变化的环境反射；反射不依赖时间随机闪烁，也不额外生成头像贴图。已经停稳的成品使用材质缓存，雕刻与移动中的圆片实时绘制，减少满盘时的重复绘制和临时缓存占用。

每件成品具有唯一编号；跨周期保留输送带与接料盘里的作品，送出带端后继续沿可见滑道落入盘中。接料盘容量为 **24 件**，满盘后自动执行 **3.8 实际秒**的换盘动作，期间保留等待队列并停止开启下一件加工：盘体、盘内成品和阴影一起沿导轨向右退出，在完全离开画面后交接库存，再将空盘沿原路送回。空盘归位后才继续加工，成品不会在可见盘内直接消失。换盘时长不随加工速度变化，暂停会冻结动作。

在普通预览中打开控制台，点击 **「更换收料盘」** 可以提前换盘；如果当前正在加工，先等本轮成品完成落料再退出收料盘。重复请求不会重启动作，重置会取消换盘并恢复初始状态；同浏览器直播标签可同步换盘请求。纯直播模式仍只显示 1080 × 1920 场景。

机架和主镜头固定，机械运动由分层图像合成实现。取放臂在水平世界平面内求解刚性连杆，再投影回照片；升降由腕部独立伸缩。演示头像使用 `assets/portrait-artwork-atlas-v1.png`：内置 imagegen 以用户参考图上的四张成品为参照重绘的高清平面插画，替代过去约 130px 宽的低清裁图。图集为 1254 × 1254、2 × 2 排列，每张原始插画 627 × 627；`makeAvatar` 默认输出 768 × 768 圆形画布。加工位、实况窗和输送带使用同一头像来源，同名观众稳定映射到同一张演示头像。
